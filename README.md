This repository contains solutions to the exercises for the Embedded Machine Learning course (Winter Semester 2026/27).

## Setup

Create and activate a virtual environment:

```bash
python -m venv .venv
.venv\Scripts\activate
```

Install the required dependencies:

```bash
pip install numpy torch matplotlib
```

## Exercises

Solutions, source code, and plots are organized into separate folders for each exercise.
